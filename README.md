# Peterbe Gg2

## How do I install these formulae?

`brew install peterbe/gg2/<formula>`

Or `brew tap peterbe/gg2` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "peterbe/gg2"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
